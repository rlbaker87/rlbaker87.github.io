Online Medical Control Training

A branching scenario module that captures 32 individual learner decisions and transmits detailed performance data to the LMS for clinical competency assessment.

32 Decision Variables Tracked
4 Branching Clinical Scenarios
5 Module Curriculum
100% SCORM Transmission Validated

The Challenge

Emergency Medicine residents and new attending physicians needed realistic practice managing EMS calls before live base station shifts, but standard quiz-based eLearning could not capture the nuanced clinical decision-making required for competency evaluation.

The final module in a five-module curriculum needed to track 32 discrete decision points across four clinical scenarios and send granular performance data to the LMS for faculty review. Beyond the design challenge, initial pilot testing failed when zero interaction data reached the LMS despite the JavaScript appearing to execute correctly. Standard SCORM troubleshooting approaches did not resolve the issue, requiring a deeper diagnostic process before implementation could proceed.

Curriculum Architecture

Five separate modules built across two authoring tools, sequenced from foundational knowledge through scenario-based performance assessment.

Module 1 EMS System Overview Articulate Rise 360
Module 2 Communication Protocols Articulate Rise 360
Module 3 Ethical Decision-Making Articulate Storyline 360
Module 4 Base Station Workflow Articulate Rise 360
Module 5 Scenario-Based Assessment Articulate Storyline 360

Solution

  • Built four branching clinical scenarios covering field termination, POLST/DNR protocols, capacity assessment, and STEMI transport — each tracking learner decisions at every critical juncture including communication approach, clinical protocol adherence, ethical decision-making, and documentation workflow.
  • Implemented 32 Storyline variables that capture both correct decisions and specific error patterns, including violating DNR orders, forcing transport without capacity assessment, and selecting non-PCI facilities for STEMI patients.
  • Used AI-assisted diagnostics to identify that Articulate Storyline 360 uses a proprietary SCORM wrapper instead of the industry-standard API — the root cause of the data transmission failure during pilot testing.
  • Built custom JavaScript that normalizes Storyline variable formats to SCORM-compliant values, prevents text overflow errors in reflection responses, and ensures trigger timing does not terminate the session before data transmission completes.
  • Created dispatch summary slides with conditional feedback that display different performance assessments based on learner variable states, showing immediate consequences of clinical decisions rather than a generic score.
  • Developed an SME interpretation guide that translates the 32 variable data points into actionable insights about learner readiness, knowledge gaps, and areas requiring remediation before live shifts.
Technical Problem Solved

Storyline's proprietary SCORM wrapper does not expose the standard API object at the window level. The fix required custom JavaScript to locate the LMS interface through the parent frame chain, normalize variable output formats, and sequence data transmission ahead of session termination. All 32 variables now transmit reliably, confirmed through SCORM Cloud validation testing.

Impact & Results

  • First training of its kind for this program — no prior eLearning equivalent existed for Emergency Medicine base station preparation.
  • Required prerequisite for all incoming Emergency Medicine residents and new attending physicians before live base station shifts.
  • All 32 decision variables transmit successfully to Cornerstone LMS, confirmed through SCORM Cloud validation testing.
  • Faculty can review detailed learner performance data beyond simple pass/fail scores, including specific protocol violations, communication errors, and ethical decision-making patterns.
  • Scoring and feedback system produces individualized performance data for each learner without requiring manual review by a supervisor, giving program leadership cohort-wide visibility into readiness.
